# Community page: classic editorial design

Outcome: visitors can understand the community rhythm, compare the three monthly memberships, and find the enquiry route without mistaking it for payment or automatic enrollment.

Matches the mission page with existing Playfair Display and Inter fonts, navy/cream/gold colors, shared community photography, numbered sections and restrained borders. Prices and benefits are unchanged. Membership cards stack until desktop to keep long benefit names readable on tablets. Each action states that it is an enquiry; contact remains the destination.

Run `bash scripts/check-community.sh`. Browser verification covers 390, 768 and 1440 pixel widths: one main heading, three membership options, correct contact links, working membership anchor, no overflow or browser errors. No real membership requests or payments are submitted.
