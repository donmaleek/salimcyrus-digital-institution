# Mission page: classic editorial design

Outcome: visitors can distinguish the purpose, four commitments, and next action without interpreting a grid of interchangeable cards.

Uses existing Playfair Display and Inter fonts, navy/cream/gold palette, shared responsive hero imagery, numbered editorial rows, and three labeled sections. Existing mission pillars remain intact. Expanded explanatory copy makes no claims about measured results or participant counts.

Verify with the mission Jest test, mission content eval, and browser checks at 390, 768, and 1440 pixels. Browser checks should confirm no horizontal overflow, a single page heading, four pillars, working purpose anchor and participation links, and no console errors.
