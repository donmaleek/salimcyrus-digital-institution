# Book Now images

The former 48px circular thumbnails have been removed. The guided booking flow
now shows compact session-type choices first and uses one full-width 16:9 image
in the selected type's supporting help panel, beneath its text. Uploaded images
retain their proportions with an upper-center cover crop. Missing images use a
matching initials fallback.

See [Guided booking](../booking/guided-booking.md) for the flow, verification
commands and deployment details. Prices and session choices remain readable
without relying on photographs or text overlays.
